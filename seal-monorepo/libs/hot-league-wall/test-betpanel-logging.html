🔧 BetPanel Logging Test

This page demonstrates how to fix the issue where BetPanel logging doesn't work after setting localStorage values.

Problem

When you set sentry_component_log_level_BetPanel = "info" in localStorage, but BetPanel still doesn't log anything.

Root Cause

The issue is that the Sentry system only reads localStorage values during initialization. After setting localStorage values, you need to either:

  1. Call initializeSentryForProject() to reinitialize the entire system
  2. Call refreshComponentConfig('BetPanel') to refresh just that component
  3. Call refreshAllComponentConfigs() to refresh all components

Console Commands

You can also run these commands directly in the browser console:

// Set BetPanel log level
setComponentLocalStorageConfig('BetPanel', { logLevel: 'info' });

// Apply the configuration (choose one):
refreshComponentConfig('BetPanel');           // Refresh just BetPanel
refreshAllComponentConfigs();                 // Refresh all components
initializeSentryForProject();                 // Reinitialize entire system

// Test logging
logInfo('BetPanel', 'This is a test message');

// Check configuration
showConfiguration();
getCurrentConfiguration();
