Instructions

  1. Click "Check Status" to see the current localStorage settings
  2. Click "Disable Logging" to set hot-league-wall-debug-enabled to false
  3. Click the test buttons to see which console methods still work
  4. Click "Enable Logging" to set hot-league-wall-debug-enabled to true
  5. Click the test buttons again to see the difference

Expected Behavior:

  • When logging is disabled: Only console.warn and console.error should work
  • When logging is enabled: All console methods should work
