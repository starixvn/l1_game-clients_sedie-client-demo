🚀 How to Test SSO Failure Handling

1. Start the Development Server

Run your development server to see the RNG Soccer prototype:

npm run dev

2. Look for the SSO Controls

In the top-right corner of the page, you'll see a small control panel:

  • "Show SSO Controls" button
  • Click it to expand the controls

3. Enable SSO Failure Simulation

In the expanded controls:

  • Click "Enable SSO Failures" (button turns green)
  • You'll see: SSO Failure Simulation: 🟢 ON

4. Test Different Failure Scenarios

Now click the "Play Now" button in the game:

  • Persistent Failure Mode: All SSO requests will fail continuously
  • First Click Invalid Token: First click returns invalid token, subsequent clicks work normally
  • Mixed Scenarios: Combine different failure types using the scenario selector

5. Observe the Enhanced UX

You'll see the improved error handling:

  • ✅ Loading state: "Loading..." on Play button
  • ✅ Token handling: Invalid tokens are handled by the main app logic
  • ✅ Real flow testing: Always uses real token request flow
  • ✅ No page refresh: Smooth error recovery

6. Test Retry Functionality

After seeing the error:

  • The app handles token failures internally
  • SSO retry logic is managed by the main application
  • Test different scenarios using the scenario selector

7. Reset and Test Success

To test successful login:

  • Click "Disable SSO Failures" (button turns red)
  • Select "Normal Flow" scenario for standard behavior
  • Click "Play Now" - should work normally
